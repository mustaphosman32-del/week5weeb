# SpendWise Budget Tracker## Project OverviewSpendWise is a simple budget tracking application built using HTML, CSS, and JavaScript. It helps users enter their total budget and expenses, calculate total spending, and determine their remaining balance.## Features- Collects a budget using JavaScript prompts.- Collects rent, food, transport, and other expenses.- Calculates total expenses.- Calculates the remaining balance.- Displays results on the webpage.- Prints clearly labeled results in the browser console.- Checks whether the budget has been exceeded.- Validates user input to prevent invalid or negative amounts.## JavaScript Concepts Implemented### 1. Variables and Data TypesThe project uses `let` variables to store the budget, individual expenses, total expenses, and remaining balance. It uses `const` for the application name and other values that do not need reassignment.The project uses strings for text, numbers for financial calculations, and Boolean conditions in decision-making.### 2. Collecting User InputThe `prompt()` function asks users to enter their budget and expenses. The `Number()` function converts the input into a number so JavaScript can perform calculations.Input validation ensures that users enter valid, non-negative amounts.### 3. Budget CalculationsThe `calculateTotalExpenses()` function adds rent, food, transport, and other expenses.Formula:Total Expenses = Rent + Food + Transport + Other ExpensesThe `calculateRemainingBalance()` function subtracts total expenses from the total budget.Formula:Remaining Balance = Total Budget - Total ExpensesA negative remaining balance means the user has exceeded the budget.### 4. Reusable FunctionsThe project uses reusable functions to organize the code:- `getAmount()` collects and validates user input.- `calculateTotalExpenses()` calculates total spending.- `calculateRemainingBalance()` calculates the remaining balance.- `formatCurrency()` formats amounts in Kenyan shillings.- `runSpendWise()` manages the complete budget calculation process.Functions make the code easier to read, maintain, test, and reuse.### 5. Displaying ResultsThe application uses `document.getElementById()` to update the dashboard. It uses `console.log()` to display a labeled budget report in the browser console.### 6. Decision-MakingThe project uses `if...else` statements to determine whether the user is within budget, has used the entire budget, or has exceeded the budget.## Technologies Used- HTML5- CSS3- JavaScript## How to Run the Project1. Download or clone the project repository.2. Open `index.html` in a web browser.3. Click **Enter Budget and Calculate**.4. Enter your budget and expenses when prompted.5. View the results on the dashboard.6. Open the browser developer tools and select the Console tab to see the budget report.## Project Files- `index.html` - Defines the webpage structure.- `style.css` - Styles the dashboard and makes it responsive.- `script.js` - Handles input, calculations, functions, and console output.- `README.md` - Documents the project and explains its features.## AuthorSalah Omar
